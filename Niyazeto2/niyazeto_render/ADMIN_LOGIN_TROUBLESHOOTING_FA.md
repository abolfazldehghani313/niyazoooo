# رفع خطای ورود پنل مدیریت نیازتو (اجرای محلی در VS Code)

## علت اصلاح‌شده
در نسخه قبلی، تابع عمومی API هر پاسخ HTTP 401 را به‌عنوان پایان نشست تلقی می‌کرد؛ حتی پاسخ 401 خود درخواست ورود. در نتیجه اگر رمز اشتباه بود، پیام گمراه‌کننده «زمان نشست مدیریت به پایان رسید» نمایش داده می‌شد. این رفتار اصلاح شد: خطای ورود اکنون پیام واقعی نام کاربری/رمز اشتباه را نشان می‌دهد و توکن قدیمی به درخواست ورود ارسال نمی‌شود.

## اطلاعات ورود محلی
اگر فایل `backend/.env` نساخته‌اید و متغیر محیطی دیگری تنظیم نکرده‌اید، مقدار پیش‌فرض کد چنین است:
- نام کاربری: `abolfazl`
- رمز عبور: `1991218771`

اگر `backend/.env` دارید، مقادیر `ADMIN_USERNAME` و `ADMIN_PASSWORD` همان فایل ملاک هستند و بر مقدار پیش‌فرض اولویت دارند. فایل `.env.example` به‌تنهایی به‌صورت خودکار بارگذاری نمی‌شود؛ باید آن را به `.env` کپی کنید و مقادیرش را تنظیم کنید.

## اجرای بک‌اند در VS Code
از ترمینال VS Code وارد پوشه `backend` شوید و اجرا کنید:

```powershell
cd backend
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

سپس در `backend/.env` برای اجرای محلی حداقل این مقادیر را تنظیم کنید (رمز دلخواه و قوی خودتان را جایگزین کنید):

```env
ADMIN_USERNAME=abolfazl
ADMIN_PASSWORD=1991218771
JWT_SECRET_KEY=یک-کلید-تصادفی-طولانی-و-ثابت
```

سرور را از همان پوشه `backend` اجرا کنید:

```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

سپس در مرورگر همین کامپیوتر باز کنید: `http://127.0.0.1:8000/admin`

نکته: اگر `.env` را تغییر دادید، سرور را متوقف و دوباره اجرا کنید. `JWT_SECRET_KEY` را تا زمانی که نشست‌های صادرشده باید معتبر بمانند تغییر ندهید. برای محیط واقعی، رمز و کلید پیش‌فرض را حتماً عوض کنید و فایل `.env` را منتشر نکنید.
