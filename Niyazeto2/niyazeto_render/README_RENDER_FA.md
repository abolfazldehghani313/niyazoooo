# راه‌اندازی بک‌اند آزمایشی نیازتو روی Render

> این بسته همان بک‌اند فعلی FastAPI پروژه است؛ مهاجرت به Django REST Framework در این بسته انجام نشده است.

## انتشار با GitHub و Render
1. این ZIP را استخراج کنید.
2. تمام محتویات پوشه را در یک مخزن جدید GitHub قرار دهید (فایل `.env` عمداً در بسته نیست).
3. در Render گزینه **New + → Blueprint** را انتخاب و مخزن GitHub را متصل کنید.
4. Render فایل `render.yaml` را می‌خواند و سرویس وب و دیتابیس آزمایشی را ایجاد می‌کند.
5. پس از Deploy، آدرس سرویس را باز کنید:
   - `/health` برای بررسی سلامت
   - `/docs` برای تست API
   - `/admin` برای پنل مدیریت

## اطلاعات ورود پنل
نام کاربری از متغیر `ADMIN_USERNAME` و رمز از متغیر `ADMIN_PASSWORD` در Environment سرویس Render ساخته می‌شود. رمز تولیدشده را از بخش Environment مشاهده و محرمانه نگه دارید. آن را در اپلیکیشن یا مخزن GitHub قرار ندهید.

## آزمایش تبلیغات
1. وارد `https://YOUR-SERVICE.onrender.com/admin` شوید.
2. یک کمپین بنری بسازید و جایگاه خانه را انتخاب کنید.
3. کمپین را فعال کنید.
4. خروجی `https://YOUR-SERVICE.onrender.com/api/v1/monetization/placements` را باز کنید و بررسی کنید کمپین در پاسخ وجود دارد.
5. در اپلیکیشن، آدرس سرور را با دامنه HTTPS سرویس Render تنظیم کنید.

## محدودیت‌های تست رایگان
- سرویس رایگان ممکن است پس از بی‌کاری به خواب برود و اولین درخواست بعدی با تأخیر پاسخ دهد.
- فایل‌های آپلودی در فضای محلی سرویس رایگان پایدار نیستند و ممکن است پس از Deploy یا راه‌اندازی مجدد حذف شوند. برای تست پایدار رسانه باید فضای ذخیره‌سازی دائمی یا سرویس Object Storage اضافه شود.
- دیتابیس رایگان Render محدودیت زمانی/منابع دارد؛ برای داده مهم یا محیط واقعی از پلن پایدار استفاده کنید.
- `DEV_OTP_MODE=true` فقط برای تست است؛ کد OTP در لاگ سرور چاپ می‌شود و پیامک واقعی ارسال نمی‌شود.
- کلیدهای SMS.ir، جیبیت و درگاه پرداخت را فقط در Environment بک‌اند وارد کنید؛ در این بسته عمداً تنظیم نشده‌اند.
