# بک‌اند آزمایشی نیازتو

این پوشه یک بک‌اند اولیه و قابل اجرا با FastAPI و SQLite است. فایل‌های Gradle، تنظیمات SDK و کد اندروید پروژه اصلی تغییر داده نشده‌اند.

## پیش‌نیاز
- Windows 10/11
- Python 3.10 یا جدیدتر
- VS Code با افزونه Python (اختیاری ولی پیشنهادی)

## اجرا در ویندوز (PowerShell)
از ترمینال VS Code وارد پوشه `backend` شوید:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

اگر PowerShell اجازه فعال‌سازی محیط را نداد، این دستور را فقط برای همان پنجره اجرا کنید و سپس فعال‌سازی را تکرار کنید:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## تست
- صفحه اصلی: http://127.0.0.1:8000
- سلامت سرور: http://127.0.0.1:8000/health
- مستندات و تست API: http://127.0.0.1:8000/docs

## APIهای آماده
- `POST /api/v1/auth/request-otp` درخواست کد ورود آزمایشی
- `POST /api/v1/auth/verify-otp` تأیید کد و دریافت JWT
- `GET /api/v1/ads` فهرست آگهی‌ها (عمومی)
- `POST /api/v1/ads` ثبت آگهی (نیازمند `Authorization: Bearer <token>`)
- `DELETE /api/v1/ads/{id}` حذف نرم آگهی متعلق به کاربر

### احراز هویت شاهکار جیبیت

- `POST /api/v1/identity/shahkar/check` (نیازمند JWT) تطبیق کد ملی با شماره موبایل همان حساب واردشده را از سرویس شاهکار جیبیت انجام می‌دهد.
- تنظیمات اتصال در `backend/.env`: `JIBIT_API_BASE_URL`، `JIBIT_IDE_API_KEY` و `JIBIT_IDE_SECRET_KEY`.
- کلیدهای جیبیت فقط در بک‌اند نگهداری می‌شوند؛ اپ فقط کد ملی را ارسال می‌کند و شماره موبایل از حساب کاربر خوانده می‌شود.
- صفحه «حساب کاربری ← اطلاعات شخصی و احراز هویت» به این API متصل شده است. کاربر ابتدا باید در بخش کیف پول با OTP وارد شود و آدرس بک‌اند را تنظیم کند.

### ورود آزمایشی
در `.env` مقدار `DEV_OTP_MODE=true` است. با درخواست کد، OTP تصادفی در ترمینال VS Code چاپ می‌شود؛ این حالت فقط برای تست محلی است و پیامک واقعی ارسال نمی‌کند. کد را در `/docs` برای endpoint تأیید وارد کنید.

## دیتابیس
در اجرای اول فایل `niyazeto.db` در پوشه backend ساخته می‌شود. دیتابیس SQLite است و برای آزمایش محلی مناسب است. بعداً می‌توانیم با تغییر `DATABASE_URL` و نصب درایور مناسب، PostgreSQL یا MySQL را جایگزین کنیم.

## اتصال گوشی واقعی
کامپیوتر و گوشی باید روی یک شبکه Wi-Fi باشند. آدرس `127.0.0.1` را در گوشی استفاده نکنید؛ به‌جای آن IP محلی کامپیوتر را بگذارید، مانند `http://192.168.1.20:8000`. IP واقعی را با `ipconfig` در ویندوز پیدا کنید. ممکن است لازم باشد اجازه دسترسی Python به شبکه خصوصی را در Windows Firewall بدهید. برای شبیه‌ساز Android Studio معمولاً آدرس میزبان `http://10.0.2.2:8000` است.

## مهم - قبل از انتشار
- ورود OTP/کیف پول و صفحه تطبیق شاهکار در اپ به API بک‌اند متصل شده‌اند؛ سایر سرویس‌های جیبیتِ موجود در فایل OpenAPI (مانند OCR، کوبانک و دایرکت‌دبیت) در این نسخه فعال نشده‌اند.
- SMS.ir هنوز متصل نیست؛ برای آن باید API Key و الگوی OTP پنل شما به‌صورت امن در بک‌اند پیکربندی شود. کلید پیامکی را در اپ اندروید قرار ندهید و آن را در چت ارسال نکنید.
- OTP در حافظه نگهداری می‌شود و با خاموش شدن سرور از بین می‌رود؛ برای محیط واقعی باید ذخیره‌سازی/محدودسازی امن، rate limit، ثبت رویداد و ارسال واقعی پیامک اضافه شود.
- مقدار `JWT_SECRET_KEY` در `.env` فقط برای محیط محلی است؛ برای سرور واقعی یک کلید تصادفی اختصاصی و HTTPS الزامی است. فایل `.env` را منتشر نکنید.
- قبل از انتشار، migration دیتابیس، اعتبارسنجی شماره‌ها، محدودیت درخواست OTP، آپلود امن فایل، مجوزها و تست‌ها باید تکمیل شوند.

## پنل مدیریت نیازتو

پس از نصب وابستگی‌ها و اجرای سرور، پنل مدیریت از مسیر زیر در دسترس است:

- پنل: `http://127.0.0.1:8000/admin`
- مستندات API: `http://127.0.0.1:8000/docs`

اطلاعات ورود آزمایشی از فایل `.env` خوانده می‌شود:

- نام کاربری: `abolfazl`
- رمز عبور: `1991218771`

**قبل از هرگونه استفاده روی شبکه یا انتشار، مقدار `ADMIN_PASSWORD` و `JWT_SECRET_KEY` را در `.env` به مقادیر تصادفی و محرمانه تغییر دهید.** فایل `.env` را در اختیار دیگران قرار ندهید.

### امکانات پنل

- داشبورد آمار کاربران، آگهی‌ها و کمپین‌های فعال
- مشاهده کاربران و فعال/مسدود کردن حساب
- مشاهده آگهی‌ها، فعال/غیرفعال کردن و حذف آگهی
- ساخت، ویرایش، توقف و حذف کمپین تبلیغاتی
- پشتیبانی از تبلیغات بنری و بینابینی (تمام‌صفحه)
- آپلود مستقیم تصویر JPG/PNG/WEBP/GIF (حداکثر ۸ مگابایت) و ویدئوی MP4/WEBM/MOV (حداکثر ۲۵ مگابایت) از پنل مدیریت
- امکان ثبت URL تصویر و ویدئو بدون آپلود
- تعیین جایگاه، اولویت، بازه شروع/پایان و سقف نمایش روزانه
- API عمومی کمپین‌های فعال: `GET /api/v1/monetization/placements`
- اپ اندروید کمپین‌های جایگاه خانه را از همین API دریافت و بنر تصویری و تبلیغ بینابینی تصویری/ویدئویی را نمایش می‌دهد.
- فایل‌های رسانه در `backend/app/uploads` ذخیره و از مسیر `/uploads/...` ارائه می‌شوند.

برای نمایش در گوشی، آدرس بک‌اند را در بخش کیف پول اپ (فیلد آدرس سرور) ثبت کنید؛ همان آدرس برای دریافت تبلیغات استفاده می‌شود. گوشی باید به سرور دسترسی شبکه داشته باشد. در انتشار واقعی از HTTPS و دامنه عمومی استفاده کنید؛ فعال بودن HTTP در Manifest فقط برای تست شبکه محلی است.
